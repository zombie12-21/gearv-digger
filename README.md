# 九幽：四门秘录

一个以中国古代盗墓门派为题材的纯前端浏览器游戏原型。

## 新增内容

- 四把传承特殊武器：玄铁摸金锹、分金定穴尺、龙纹开山斧、追魂匕首
- 武器稀有度、伤害、特殊效果与门派专属触发
-朱砂符、回春丹、夜明珠、青铜镇墓兽、金蚕丝、牵魂铃、九幽残片、避邪铜镜
- 守墓战斗、敌人反击、战利品掉落与机关核心收集

## 门派

- 摸金派：机关与古物辨识
- 发丘派：风水与墓穴脉络
- 搬山派：破拆与正面攻坚
- 卸岭派：潜行、伪装与情报

## 本地运行

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

也可直接通过任意静态服务器部署所有前端文件。
