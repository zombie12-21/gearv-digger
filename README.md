# 九幽：四门秘录

一个以中国古代盗墓门派为题材的纯前端浏览器游戏原型。

## 门派

- 摸金派：机关与古物辨识
- 发丘派：风水与墓穴脉络
- 搬山派：破拆与正面攻坚
- 卸岭派：潜行、伪装与情报

## 本地运行

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

也可直接通过任意静态服务器部署 `index.html`、`styles.css` 和 `game.js`。

## 当前原型

- 门派选择界面
- 古墓探索场景
- 四项行动与状态变化
- 体力、铜钱、名望、业障与物品栏
- 响应式桌面和移动端布局
